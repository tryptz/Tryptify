联系

如需 Tryptify Cloud、账单、退款、个人数据或其他任何方面的帮助：

support@tryptify.com

我们会在 3 个工作日内回复。账单问题请附上你结账时使用的电子邮件地址。

报告问题或参与开发 Tryptify

发现了问题？在 GitHub 上提交 issue。请写明你做了什么、预期的结果和实际发生的情况，并附上你的手机型号、Android 版本和应用版本（设置 › 关于）。

想参与开发？Tryptify 是开源的。发送邮件至 support@tryptify.com，说说你想参与的内容，比如代码、翻译、主题或测试；也可以直接认领 GitHub 上的待解决 issue。

版权通知

如需举报存储在 Tryptify Cloud 中侵犯你版权的内容，请写信至同一地址，并附上作品及相关内容的详细信息。
