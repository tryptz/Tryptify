服务条款

本条款适用于 tryptz（以下称“我们”）提供的付费音乐存储服务 Tryptify Cloud，以及你用于登录该服务的 Tryptify 账号。开始试用或订阅，即表示你同意本条款。Tryptify 应用本身是依据 GNU 通用公共许可证第 3 版（GPL v3）发布的免费开源软件；应用的代码受该许可证约束，而不受本条款约束。

1. 服务内容

Tryptify Cloud 存储你上传的音乐文件，并通过 Subsonic API 将其串流回传给你，供你在 Tryptify 应用中播放。各套餐及其存储空间和价格见价格页面。

2. 你的账号

使用 Tryptify Cloud 需要 Tryptify 账号，你有责任妥善保管账号的登录凭据。你必须年满 16 周岁；如果你所在地的数字同意年龄更高，则须达到该年龄。每个账号仅限一人使用，不得共享。

3. 付款与续订

付款由我们的记录商户（merchant of record）Creem（creem.io）处理。Creem 是你此次购买的记录卖方，其自身的条款同样适用于该笔付款。订阅按月或按年预先收费，并以相同价格自动续订，直至你取消。价格可能已含或另加销售税或增值税，以结账时显示为准。如果我们调整价格，新价格自我们通知你之后的下一次续订起生效，你可以在此之前取消。

4. 免费试用

每个账号可享受一次 7 天免费试用，含 20 GB 存储空间，仅适用于月付套餐。开始试用需要提供支付卡。如果你未在试用结束前取消，你所选的套餐将开始生效，并从你的卡中扣取首月费用。

5. 取消

你可以随时在应用中（设置 › 连接 › Tryptify Cloud › 管理或取消订阅）或通过 Creem 邮件中的链接取消订阅。在你已付费的周期结束前，套餐仍然有效。退款事宜请参阅我们的退款政策。

6. 套餐终止后

套餐因取消或付款失败而终止后，你的音乐库将在 7 天内处于只读状态：你仍可播放和下载音乐，但无法上传。7 天期满后，你的文件和音乐库将被永久删除。如发生退款或拒付（chargeback），该期限为 2 天。

7. 你的音乐

你保留对所上传内容的全部权利。你仅授予我们存储、处理（例如读取标签和封面）以及向你串流回传这些文件所必需的许可。你只能上传你拥有或有权复制的音乐，且仅供个人收听。Tryptify Cloud 不得用于分发或公开分享音乐。对于违反本条或法律的内容和账号，我们可以删除内容并暂停账号，包括在收到发送至下方地址的有效版权通知之后。

8. 禁止成人或 NSFW 内容

Tryptify Cloud 和你的 Tryptify 账号不得用于任何 NSFW（不适合在工作场合观看）的用途。你不得以任何形式上传、存储、串流、分享或展示露骨的色情内容、裸露内容、色情作品或其他任何成人内容，包括：音乐文件及其封面、文件名和标签、你的头像和名称、主题商店中的主题及其图片，以及听歌派对中的消息。无论这些内容在你所在地是否合法，本条均适用。我们一经发现或接到举报，即会删除此类内容，并可能暂停或关闭发布该内容的账号。如需举报，请发送邮件至 support@tryptify.com。

9. 合理使用与限制

每个套餐都有存储上限。达到上限后将无法继续上传；超出上限绝不会向你额外收费。单个文件最大 2 GB。不得试图破坏、超载或规避本服务的限制或安全措施，也不得用本服务存储音乐及其封面以外的任何内容，且封面须遵守第 8 条。

10. 可用性与原始文件

我们会尽力保持 Tryptify Cloud 快速、可用，但本服务按“现状”提供，不保证服务不间断。它是串流服务，而不是备份：请始终自行保留文件的副本。

11. 责任

在法律允许的范围内，我们不对间接损失、后果性损失或数据丢失承担责任，且我们对你承担的全部责任以你在提出索赔前 12 个月内向我们支付的金额为限。本条款中的任何内容均不限制你作为消费者依法享有、且不得通过合同加以限制的权利。

12. 服务终止

对于严重或多次违反本条款的账号，我们可以暂停或关闭。如果我们停止提供 Tryptify Cloud，将至少提前 30 天通知你，以便你下载音乐，并退还任何未使用的预付期间的费用。

13. 条款变更

我们可能会更新本条款。如有重要变更，我们会在变更生效前通过应用或电子邮件通知你。此后继续使用本服务，即表示你接受新条款。
