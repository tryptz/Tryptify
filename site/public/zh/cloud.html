Tryptify Cloud

基于 Subsonic API 的个人音乐存储，专为快速串流打造。

自己的音乐上传一次，就能在 Tryptify 里随处播放：不用在家开着电脑，不用搭服务器，也不用设置端口转发。

使用方法

  1. 登录 Tryptify，打开“设置 › 连接 › Tryptify Cloud”。
  2. 选择套餐或开始免费试用。付款页面会在浏览器中打开。
  3. 上传歌曲：在应用的“音乐库 › 本地”中打开歌曲菜单，点按“上传到 Tryptify Cloud”。
  4. 随处播放：在“音乐库 › 我的服务器”和搜索中都能找到，保持原始音质。

服务内容

基于 Subsonic API

你的音乐库使用开放的 Subsonic API，和 Navidrome 是同一套接口，所以浏览和拖动进度都和家用服务器一样。

仅你可见

只有你的账号能查看或播放你的音乐库。每台设备都用各自的随机密码登录，绝不使用你的账号密码。

格式

FLAC、ALAC、MP3、AAC/M4A、Ogg Vorbis、Opus、WAV、AIFF、APE 和 WMA，每个文件最大 2 GB，支持封面。
