音频链路

从文件到耳朵，一条完整的链路。

每首歌在应用里都走同一条路径。每个环节都由你决定：开启、调整，或者不去动它。

  1. ♪你的音乐手机里的文件、你自己的 Subsonic 服务器、Tryptify Cloud 或流媒体。
  2. ≋完整分辨率24 位和 32 位文件全程以浮点格式处理。
  3. ⫶DSP 调音台总线和效果链，共 36 个插件，以 LUFS 计量响度。
  4. ◠耳机 EQ先套用你耳机型号的 AutoEQ，再叠加你自己的参数均衡器。频谱和视觉效果都从这里取信号。
  5. ⇄速度与音高按倍速、半音或 BPM 加快或放慢。
  6. ◉输出按歌曲自身的采样率直接送到 USB DAC，或经由 Android 输出到蓝牙设备和扬声器。

歌词

体积光照亮的歌词。

时间同步的歌词以玻璃字体呈现，光线从正在演唱的那一行倾泻而出。九种样式可选，从 Sunburst 到 Sea Glass；也可以自己调整光线：跟随正在演唱的字词，加上尘埃、节拍闪光或缓慢环绕。

发现

把音乐库变成一片星系。

“发现”是一张可以在其中飞行的流派地图。“音乐库星系”把你手机上的每位艺人化作夜空中的一颗星，挨着其所属的流派。可以按任何名称搜索：输入“dnb”就能找到 drum and bass。

混音器

是调音台，不是预设菜单。

用 36 个插件搭建总线和效果链，插件分为六组：EQ 与滤波器、动态、失真、调制、空间和工具。每个旋钮都真正起作用，每条效果链都能保存。

视觉效果

看得见的声音。

封面上的玻璃频谱、显示歌曲最近几秒的山脊图、瀑布图，以及在 projectM 上实时运行的 9,795 个 MilkDrop 预设。

速度与音高

速度随意，音高由你。

可以按倍速或半音调整速度，也可以直接设定 BPM。音高可以保持不变，也可以像唱盘一样随速度一起变。

听歌派对

一起听，分秒不差。

开一个派对，把代码或链接发出去。朋友可以在应用里加入，也可以直接用网页浏览器加入，所有人听到的都是同一首歌的同一刻。播放时可以往共享的“接下来”里加歌、投票跳过、聊天。你手机里的歌曲排进队列后，会串流给没有这首歌的人，而且不会留在任何人那里。

Trypt Mania · 测试版

用你自己的音乐玩节奏游戏。

Trypt Mania 用你音乐库里的歌曲来玩 StepMania 风格的谱面。可以导入曲包，也可以在谱面编辑器里自己做。它有独立的播放器，所以玩一局不会动到你的播放队列、收听记录同步（scrobble）或状态。

Trypt Mania 多人游戏

StepMania 式的同场对战。

创建房间，或用代码加入，房间里还能聊天。房主选好谱面后，所有人同时开玩，旁边的实时榜单列出每个人的分数和连击。有人没有这首歌？房主把它分享给房间，对方点一下就能加入。

液态玻璃

会折射光线的玻璃。

导航栏、迷你播放器、搜索栏和面板会像真正的玻璃一样，在边缘折射后面的内容，并随正在播放的音乐着色。二十多种玻璃样式，从 Float 到 Holo。

主题与字体

先打造自己的风格，再分享出去。

十五种文本样式，每种都可以单独设置字体、字重、字号和字宽。整套外观可以打包成一个主题，自选包含哪些部分，发布到主题商店或直接用分享码分享；别人的主题也能先实时试用，再决定是否保留。你的字体文件、蓝牙延迟和音质设置始终只留在你的手机上。

音乐联动

让任何设置随音乐而动。

点按滑块旁的 ♪，或长按它，这项设置就会随歌曲而动：跟着底鼓、人声、军鼓、踩镲，或你选定的频段。视觉效果、玻璃、歌词的光线，甚至混音器的旋钮都可以。所有联动都列在一个页面里，可以暂停、修改或删除。

Tryptify Cloud

不想自己架服务器？

Tryptify Cloud 是基于 Subsonic API 的个人音乐存储，专为快速串流打造。在应用里把音乐上传一次，就能随处播放。套餐 100 GB 每月 $3.99 起，提供 7 天免费试用。
