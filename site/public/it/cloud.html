Tryptify Cloud

Il tuo archivio musicale personale con API Subsonic, pensato per uno streaming veloce.

Carica la tua musica una volta e ascoltala ovunque in Tryptify: niente computer acceso a casa, niente server da configurare, niente port forwarding.

Vedi i piani Scarica l'app

Come funziona

  1. Accedi a Tryptify e apri Impostazioni › Connessioni › Tryptify Cloud.
  2. Scegli un piano o avvia la prova gratuita. Il pagamento si apre nel browser.
  3. Carica i brani dall'app: apri il menu di un brano in Libreria › Locale e tocca Carica su Tryptify Cloud.
  4. Ascoltali ovunque in Libreria › Il mio server e in Cerca, nella qualità originale.

Cosa include

Basato sull'API Subsonic

La tua libreria risponde all'API aperta Subsonic, la stessa di Navidrome, quindi la navigazione e i salti nel brano funzionano come con un server di casa.

Solo per te

Solo il tuo account può vedere o riprodurre la tua libreria. Ogni dispositivo accede con una propria password casuale, mai con la password del tuo account.

Formati

FLAC, ALAC, MP3, AAC/M4A, Ogg Vorbis, Opus, WAV, AIFF, APE e WMA, fino a 2 GB per file, con copertina.
