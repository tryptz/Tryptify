プライバシーポリシー

最終更新日：2026年10月21日

本ポリシーは、お客様が Tryptify アプリ、Tryptify アカウントおよび Tryptify Cloud を利用する際に tryptz（以下「当方」）が収集する情報と、その取り扱いについて説明するものです。当方はお客様のデータを販売せず、広告も表示しません。

アプリ

Tryptify アプリは、ライブラリ、設定、再生履歴をお客様の端末内に保存します。データが外部に送信されるのは、お客様がオンにした機能を使う場合に限られます。具体的には、お気に入りやプレイリストを同期するためのサインイン、Last.fm または ListenBrainz へのスクロブル、再生中の曲の Discord への表示、お客様ご自身の音楽サーバーへの接続、Tryptify Cloud の利用です。これらの各サービスが受け取るのは、その機能に必要な情報だけです。

Tryptify アカウント

サインイン時に、当方はお客様のメールアドレスとアカウント ID を受け取ります。Google でサインインした場合は、お名前とプロフィール画像も受け取ります。アカウントは Supabase で運用しています。

Tryptify Cloud

  • 音楽：お客様がアップロードしたファイル、そのタグ（曲名、アーティスト、アルバムなど）およびカバー。お客様にストリーミングするために保存します。
  • プラン：ご利用中のプラン、支払い済みの期限、容量の使用量、および決済事業者が発行する顧客 ID とサブスクリプション ID。
  • デバイスのサインイン情報：ライブラリを再生するデバイスごとのランダムなパスワードと、そのデバイスの名前（機種名など）。
  • 技術ログ：サービスの稼働と安全を維持するため、ホスティング事業者が短期間のリクエストログ（IP アドレスや時刻など）を保持します。

ファイルとライブラリのデータは Cloudflare（R2 ストレージと D1 データベース）に保存されます。

支払い

支払いは、当方の販売事業者（Merchant of Record）である Creem（creem.io）が、Creem 自身のプライバシーポリシーに基づいて処理します。当方がお客様のカード番号を閲覧または保存することはありません。Creem から当方に伝えられるのは、支払いの有無、対象のプラン、有効期限のみです。

保存期間

音楽とライブラリは、プランの終了から 7 日後（返金またはチャージバックの場合は 2 日後）に削除されます。お客様からご依頼があれば、それより早く削除します。請求記録は、税法で定められた期間保管します。アカウントは、お客様から削除のご依頼があるまで保持します。

お客様の権利

support@tryptify.com までご連絡いただくことで、データのコピー、訂正または削除を請求できます。お住まいの地域（EU、英国、カリフォルニア州など）によっては、データ保護機関へ苦情を申し立てる権利を含め、さらに権利が認められる場合があります。

お子様について

Tryptify Cloud は 16 歳未満の方を対象としておらず、当方が 16 歳未満の方のデータを故意に収集することはありません。

変更

本ポリシーを重要な点で変更する場合は、適用前にアプリ内またはメールでお知らせします。
