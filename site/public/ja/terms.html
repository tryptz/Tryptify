本規約は、tryptz（以下「当方」）が提供する有料音楽ストレージ Tryptify Cloud と、そのサインインに使用する Tryptify アカウントに適用されます。お客様は、トライアルまたはサブスクリプションを開始することにより、本規約に同意したものとみなされます。Tryptify アプリ自体は GNU General Public License v3 に基づく無料のオープンソースソフトウェアであり、アプリのコードには本規約ではなく同ライセンスが適用されます。

第1条（本サービス）

Tryptify Cloud は、お客様がアップロードした音楽ファイルを保存し、Tryptify アプリで再生できるよう、Subsonic API を通じてお客様にストリーミングします。各プラン、その容量および料金は料金ページに記載しています。

第2条（アカウント）

Tryptify Cloud の利用には Tryptify アカウントが必要です。そのサインイン情報を安全に管理する責任はお客様にあります。ご利用は 16 歳以上の方に限ります。お住まいの地域のデジタル同意年齢がそれより高い場合は、その年齢以上の方に限ります。アカウントは 1 人につき 1 つとし、共有しないでください。

第3条（支払いと更新）

支払いは、当方の販売事業者（Merchant of Record）である Creem（creem.io）が処理します。お客様の購入における販売者は Creem であり、支払いには Creem 自身の規約も適用されます。サブスクリプションは月払いまたは年払いの前払いで請求され、解約されるまで同じ価格で自動的に更新されます。価格には、購入手続き時の表示に従い、売上税または VAT が含まれるか、加算される場合があります。当方が価格を変更する場合、変更は当方からの通知後に迎える次回の更新から適用され、お客様はそれまでに解約することができます。

第4条（無料トライアル）

20 GB の容量が付いた 7 日間の無料トライアルを、月額プランについて、アカウントごとに 1 回提供します。開始には支払い用カードが必要です。トライアル終了前に解約されなかった場合は、選択されたプランが開始され、最初の 1 か月分がカードに請求されます。

第5条（解約）

解約は、アプリ（「設定 › 接続 › Tryptify Cloud › サブスクリプションの管理・解約」）または Creem からのメールに記載されたリンクから、いつでも行えます。支払い済みの期間が終わるまでは、プランを引き続きご利用いただけます。返金については返金ポリシーをご覧ください。

第6条（プラン終了時の扱い）

解約または支払いの失敗によりプランが終了すると、ライブラリは 7 日間、読み取り専用になります。この間、音楽の再生とダウンロードはできますが、アップロードはできません。7 日間が経過すると、ファイルとライブラリは完全に削除されます。返金またはチャージバックの後は、この期間は 2 日間となります。

第7条（お客様の音楽）

アップロードしたものに関するすべての権利は、お客様が保持します。当方がお客様から許諾を受けるのは、ファイルの保存、処理（タグやカバーの読み取りなど）およびお客様へのストリーミングに必要な範囲に限られます。アップロードできるのは、お客様が所有する音楽、または複製する権利を有する音楽で、お客様ご自身が個人的に聴くためのものに限ります。Tryptify Cloud は、音楽の配布や一般への共有を目的としたサービスではありません。当方は、本条または法令に違反するコンテンツを削除し、そのアカウントを停止することがあります。下記のアドレスに有効な著作権侵害の通知が届いた場合も同様です。

第8条（成人向け・NSFW コンテンツの禁止）

Tryptify Cloud およびお客様の Tryptify アカウントは、NSFW（not safe for work、職場での閲覧に不適切）なものに一切使用できません。性的に露骨なコンテンツ、ヌード、ポルノ、その他のアダルト素材は、形式を問わず、アップロード、保存、ストリーミング、共有、表示してはなりません。対象には、音楽ファイルとそのカバーアート、ファイル名とタグ、プロフィール画像と名前、テーマストアのテーマとその画像、リスニングパーティーのメッセージが含まれます。これは、その素材がお住まいの地域で合法であるか否かにかかわらず適用されます。当方は、そのようなコンテンツを発見した場合または報告を受けた場合に削除し、投稿したアカウントを停止または閉鎖することがあります。報告は support@tryptify.com までお送りください。

第9条（公正な利用と制限）

各プランには容量の上限があります。上限に達するとアップロードは停止し、超過による追加料金が請求されることはありません。1 ファイルの上限は 2 GB です。本サービスの制限やセキュリティを破る、過負荷をかける、または回避する行為を試みないでください。また、音楽とそのカバーアート（第8条に従うものに限ります）以外のものを保存する目的で本サービスを使用しないでください。

第10条（可用性とお客様の元ファイル）

当方は Tryptify Cloud の速度と可用性の維持に努めますが、本サービスは「現状のまま」提供され、中断なく利用できることを保証するものではありません。本サービスはストリーミングサービスであり、バックアップではありません。ファイルのコピーは必ずお客様ご自身でも保管してください。

第11条（責任）

第12条（サービスの終了）

当方は、本規約に重大または繰り返し違反したアカウントを停止または閉鎖することがあります。当方が Tryptify Cloud の提供を終了する場合は、お客様が音楽をダウンロードできるよう少なくとも 30 日前までに通知し、前払い済みの未使用期間分を返金します。

第13条（変更）

当方は本規約を更新することがあります。重要な変更の場合は、適用前にアプリ内またはメールでお知らせします。その後も本サービスを継続して利用された場合、お客様は新しい規約に同意したものとみなされます。
