Tryptify Cloud

高速ストリーミングのために作られた、あなた専用の Subsonic API 音楽ストレージ。

自分の音楽を一度アップロードすれば、Tryptify でどこでも再生できます。自宅のパソコンを付けっぱなしにする必要も、サーバーの設定も、ポート開放もいりません。

プランを見る アプリを入手

使い方

  1. Tryptify にサインインし、「設定 › 接続 › Tryptify Cloud」を開きます。
  2. プランを選ぶか、無料トライアルを始めます。支払い画面はブラウザで開きます。
  3. 曲をアップロードします。アプリの「ライブラリ › 端末内」で曲のメニューを開き、「Tryptify Cloud にアップロード」をタップします。
  4. どこでも再生できます。「ライブラリ › マイサーバー」と「検索」から、元の音質のまま聴けます。

主な特長

Subsonic API ベース

ライブラリはオープンな Subsonic API（Navidrome と同じ API）で応答するので、自宅サーバーと同じ感覚でブラウズやシークができます。

あなただけのライブラリ

ライブラリを閲覧・再生できるのは、あなたのアカウントだけです。各デバイスはそれぞれ専用のランダムなパスワードでサインインし、アカウントのパスワードは使いません。

対応フォーマット

FLAC、ALAC、MP3、AAC/M4A、Ogg Vorbis、Opus、WAV、AIFF、APE、WMA に対応。1 ファイル最大 2 GB で、カバーアートも保存できます。
