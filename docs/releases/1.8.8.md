# Tryptify 1.8.8

## Changed

- **Every page you swipe between is in one list.** Settings › Library › Page Order holds all seven — Home, Discover, Local, Overview, Playlists, Favorites and Downloads — and any of them can be moved anywhere in the sequence. It was "Library Tab Order" and it listed five.
- **There were two nested pagers, and now there is one.** An outer one hardcoded to Home / Discover / Library, and an inner one over the Library's sections driven by the setting — only the inner one was reorderable. The dot indicator had been flattening the two into a single strip of seven for a while, so the app was already presenting one sequence.
- **Any page can be hidden.** A hidden page grays its row out and drops out of the swipe, but keeps its slot, so switching it back on puts it where it was rather than at the end. The last visible page cannot be hidden, refused in three separate places — the last of which exists because a hidden set can arrive from another device's settings sync without this device's UI ever seeing it.
- **Discover has a Settings button.** It was the only top bar without one, which with hiding would have made "Discover is the only visible page" a three-tap way to strand yourself: no bottom nav, no drawer, and Settings the only place to bring a page back.
- **A page added in a future version will now show up for you.** Any install that had ever touched the old setting kept its five-entry list forever and never saw anything added later. New pages are inserted where they belong in the sequence rather than dropped at the end, which is where nobody finds one.
- **Your existing order carries over as what you were seeing**, not as what was stored: the old list started with Overview, but the pin meant Local was the page you actually landed on, so an upgrade puts Home and Discover first and Local after them.
- **Each page keeps its own scroll position** instead of sharing one with the rest of the Library. They reset once, on the first launch after updating.
- **"Enable Equalizer" is now "Enable AutoEQ/Equalizer".** The same switch is the master for the AutoEQ headphone correction, the tone shelves and the graphic bands — Target Curve and Headphone directly under it are both downstream of it — and the old name only claimed one of those.
- **System-wide AutoEQ is a sub-toggle now, marked Beta.** It sits indented under "Enable AutoEQ/Equalizer" and only appears while that is on. It used to sit *above* it as an equal, which read as the bigger and better of the two switches; it is neither, and it means nothing with the equalizer off.
- **The warning says what the trade actually is.** Turning it on takes the app's exact parametric correction out of the chain and replaces it with a many-band graphic-EQ approximation, because a global effect can only be a graphic EQ — and some devices ignore a session-0 effect entirely, which leaves you with no correction at all rather than a coarser one.

## Fixed

- **Turning the equalizer off now switches System-wide AutoEQ off too.** `SystemAudioEqController` watched the system-wide flag and never `eqEnabled`, so disabling the EQ from Settings or the Equalizer screen left the global session-0 effect attached and running. Only the player's own toggle had ever cleared it — and with the row now hidden while the EQ is off, that would have become a running global effect with nothing on screen left to stop it.
- **Every list row is the same height.** Songs, Artists, Genres, Folders, search results, playlists, album and genre track lists and the folder browser all lay their rows out at one shared height, so a scrolling list reads as an even column instead of a ragged one.
- **Three things used to move that height, and all three were invisible in the code.** A subtitle whose artist and album did not both fit wrapped onto a second line and made that row a whole line taller; a track whose artist is a tappable link carried the link's 8dp hit-box inset where a plain "Unknown Artist" did not; and a row whose text was shorter than its 48dp cover was sized by the cover instead.
- **The subtitle is capped at one line.** It was already capped for *many artists*, but the album is appended outside that component, so "artist • album" that did not fit still wrapped. The album ellipsizes now rather than dropping to a second line.
- **The row height follows your text size** rather than being a fixed 64dp. The app scales its own type from Settings › Theme and that multiplies with the system font scale, so a hardcoded row was right at the default and clipped the subtitle at "Larger" and "Largest". It is derived from the line heights instead.
- **`ListRowHeightTest` holds it**, walking every text-size preset against the system scale and checking each row shape the app renders — cover, title, linked subtitle, badge pills, the search row's extra gap, the folder browser's smaller artwork — so a raised line height fails there rather than on a phone.
- **"Local" can finally be moved.** It was pinned to the front in code regardless of the stored order, so moving it in Settings had never done anything and its arrows were decorative.

## Removed

- **The traveling light sheet is gone from every glass surface** — the lyric glass, the player chrome, the transport disc, the action dock, the mini player and the Studio preview. A soft diagonal band used to glide across each pane every ~7 seconds, and it is the one thing on that surface you could not look away from.
- **It was removed rather than dimmed, because a band that crosses the pane is an event, not a texture.** It travels the full width, it is the brightest thing on the glass while it does, and unlike the shimmer and the swell it has somewhere to be — so the eye follows it off the edge and then waits for the next one. At a quarter of the brightness it is still a thing that happens, just fainter.
- **Two surfaces were never obeying Surface motion anyway.** The lyric glass and the player panel pin the shader's motion uniform to 1, so the sweep ran at full strength on them no matter where the slider sat — turning it to 0 could not stop it.
- **Face swell, edge shimmer and the glint twinkle all stay**, and all of them undulate in place, so the setting still runs from perfectly still at 0 to fully alive at 1 and every shipped theme keeps its character. The slider's caption now says what it actually drives.
- **The rim is very slightly calmer as a result.** The sheet also lifted the glass's alpha as it passed; without it the edge highlight is the Fresnel rim and the glint alone, which is what "Edge highlight" was always meant to control.
