# Tryptify 1.8.8

## Changed

- **Every page you swipe between is in one list.** Settings › Library › Page Order holds all seven (Home, Discover, Local, Overview, Playlists, Favorites and Downloads) and any of them can go anywhere. It listed five before, because Discover sat in a different pager.
- **Any page can be hidden.** A hidden page keeps its slot, so switching it back on puts it where it was rather than at the end. The last visible page cannot be hidden.
- **Discover has a Settings button.** It was the only top bar without one, which with hiding was a three-tap way to strand yourself with nowhere to bring the others back from.
- **Your order carries over as what you were seeing**, so an upgrade puts Home and Discover first and Local after them. Each page keeps its own scroll position now, so those reset once.
- **"Enable Equalizer" is now "Enable AutoEQ/Equalizer".** One switch is the master for the headphone correction, the tone shelves and the graphic bands, and the old name claimed one of the three.
- **System-wide AutoEQ is a sub-toggle now, marked Beta.** It sits under the equalizer's switch instead of above it as an equal, and only appears while that is on.
- **Its warning says what the trade is:** the app's exact correction leaves the chain for a coarser global graphic EQ, and some devices ignore that entirely, which leaves you with none.

## Fixed

- **Turning the equalizer off switches System-wide AutoEQ off too.** The controller watched only the system-wide flag, so disabling the EQ left the global session-0 effect attached and running.
- **Every list row is the same height.** Songs, Artists, Genres, Folders, search results, playlists, track lists and the folder browser all lay out at one height, so a list reads as an even column.
- **Three things used to move it:** a subtitle that wrapped to a second line, a tappable artist name carrying the link's 8dp hit-box inset, and a row shorter than its 48dp cover being sized by the cover.
- **The subtitle is capped at one line** and the height follows your text size, instead of a fixed 64dp that clipped it at "Larger" and "Largest".
- **`ListRowHeightTest` holds it** across every text-size preset and every row shape the app renders.
- **"Local" can finally be moved.** It was pinned to the front in code regardless of the stored order, so its arrows in Settings were decorative.

## Removed

- **The traveling light sheet is gone from every glass surface:** the lyric glass, player chrome, transport disc, action dock, mini player and Studio preview. A soft diagonal band crossed each pane every ~7 seconds.
- **It was removed rather than dimmed**, because a band that crosses the pane is an event, not a texture; at a quarter of the brightness it is still a thing that happens. On the lyric glass and the player panel it never obeyed Surface motion at all, so turning the slider to 0 could not stop it.
- **Face swell, edge shimmer and the glint twinkle all stay.** They undulate in place, so the slider still runs from perfectly still at 0 to fully alive at 1 and every shipped theme keeps its character.
