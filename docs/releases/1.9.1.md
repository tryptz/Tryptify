# Tryptify 1.9.1

A downloads release: your download folder is now sorted by artist and album, and every album keeps its own cover.

## Changed

- **Downloads are filed by artist and album.** Each download goes into its own Artist / Album folder, numbered in track order, instead of every song piling up in one folder. A second disc follows the first in the same album folder.
- **Every album shows its own cover.** Only one cover.jpg was ever saved, so file managers and other players showed the first album you downloaded on everything after it. Each album folder now gets its own.
- **Other players find your synced lyrics.** Lyrics files were being saved with .txt on the end, so players never matched them to the song. They are saved as .lrc next to the track now.
- **The Downloads page looks inside folders.** Songs inside artist and album folders show up too, such as ones left from before a reinstall. Songs saved the old way are still found where they are.

## Removed

- **No picture file beside every song.** Downloads no longer save a separate image for each track. The cover is inside FLAC downloads, and each album folder has one cover.jpg.

## Worth knowing

- **Songs you already downloaded stay where they are.** Only new downloads use the new folders. To move an old album into them, delete it and download it again.
